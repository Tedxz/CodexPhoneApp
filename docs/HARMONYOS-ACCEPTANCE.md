# HarmonyOS 原生应用验收

用于验证 ArkTS / ArkUI 客户端在 HarmonyOS 7 / API 26 环境的构建、界面与真实会话行为。操作方法见[原生工程说明](../harmony/README.md)，后端通用检查见[验收清单](ACCEPTANCE.md)。

## 环境与构建

```sh
npm run check
npm run harmony:doctor
npm run harmony:build
```

- [ ] 记录提交版本、DevEco、SDK、系统 API 级别与构建模式。
- [ ] 自动测试及真实 ArkTS 编译、资源处理、未签名 HAP 打包通过。
- [ ] 未签名包在支持的模拟器中安装启动；真实手机使用与应用包名、设备相匹配的签名包。
- [ ] 签名配置、证书、私钥和安装包留在本地，仓库工程保持无签名。

原生逻辑测试使用系统 API 替身，不能证明真实网络、Asset Store、相册或系统布局正常；模拟器与真机应分别记录结果。

## 连接与凭据

- [ ] 输入网关地址与一次性凭据，或粘贴完整配对链接，成功进入首页。
- [ ] 添加两个独立网关，分别保存名称与登录，首页按网关展示目标机器。
- [ ] 单个网关离线或登录失效时，其他连接可正常使用。
- [ ] 修改地址只有在新入口配对成功后才替换旧连接；改名称不影响登录。
- [ ] 强制停止、冷启动和覆盖安装后，登录及安装身份按预期恢复。
- [ ] 同一 App 的多入口授权归入同一客户端，重复配对不新增重复记录。
- [ ] 移除连接只清除本地条目；退出登录和撤销客户端会使对应网关的全部入口授权失效。
- [ ] 旧版登录迁移成功；迁移失败时保留原登录并显示可恢复状态。

## 浏览与交互

- [ ] 工作路径搜索、同名目录区分、目录内会话搜索和分页正确。
- [ ] 工作路径标题无卡片背景，默认折叠；展开后直接显示会话卡片，卡片不重复目录，与路径区域齐宽，时间与标题同行；多个分组独立展开、分页、加载失败重试正确，折叠或换机器后丢弃迟到响应。
- [ ] 路径菜单能查看和复制完整路径，置顶和置底互斥、可撤销，在冷启动后恢复，并按网关与机器隔离。
- [ ] 「置底路径及子路径」覆盖该路径与各级子目录及以后出现的子目录，不匹配同名前缀的相邻目录；应用时取消范围内已有置顶，之后可单独置顶。菜单标明继承的置底来源，父路径不在列表时可从子路径取消上级规则；取消父级规则保留独立子级规则和单独置底。冷启动与切换机器后规则正确恢复和隔离。
- [ ] 在 Mate 90 Pro Max 模拟器上检查折叠路径标题及展开后的会话卡片、长名称截断和完整路径弹窗；浅色背景、系统栏与键盘布局正常。
- [ ] 全部会话与路径筛选切换时，不混用游标或迟到响应。
- [ ] 新建会话的项目、模型、推理强度和 Plan 模式到达后端。
- [ ] 流式回复、工具卡片折叠、上翻阅读、自动跟随及跳到最新位置正常。
- [ ] 草稿在会话之间隔离，返回原会话后恢复。
- [ ] 相册选择、上传与经过认证的历史图片下载及显示正常。
- [ ] 追加、停止、审批与交互问题操作正确，不重复提交。
- [ ] 各网关和机器的草稿、附件、图片缓存及审批保持隔离。

## 系统界面

- [ ] 桌面图标、启动页、应用内图标与添加连接按钮显示正常。
- [ ] 状态栏与页面背景衔接，浅色背景下系统文字可读。
- [ ] 键盘打开后标题、输入框、发送按钮仍可见，内容不与系统栏重叠。
- [ ] 收起键盘、切页、错误提示出现与关闭、冷启动后布局正常。
- [ ] 返回前台后连接恢复，后台暂停不意外停止电脑端任务。

## 真实网络与后端

- [ ] 使用隔离测试会话，在实体手机上完成文字、图片和真实增量回复。
- [ ] 本机与 SSH 目标分别完成运行中追加、停止及审批。
- [ ] HTTPS 配对、WSS 订阅与心跳均成功，保持系统 TLS 验证。
- [ ] 网关重启后自动重连并同步会话；另行记录需要重启 App 才能恢复的情况。
- [ ] 分别测试局域网、Funnel 和手机蜂窝网络，不以模拟器结果代替真机结果。

## 记录规范

报告至少包含测试版本、环境、执行步骤、通过项、失败项、阻塞项和未执行项。签名包校验值可保存在本地报告中；设备序列号、签名身份、认证信息、私人域名、真实项目路径及会话正文不进入公开仓库。原始报告和截图放在被忽略的 `tmp/` 或 `docs/evidence/` 中。
