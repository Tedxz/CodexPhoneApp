# 真实后端与手机验收

本清单用于在自己的部署环境中验证功能，不代表所有版本、设备和网络已经通过。自动测试、网页构建和 socket 文件存在，均不能替代真实跨端运行验证。原始报告与截图保存在被 Git 忽略的 `tmp/` 或 `docs/evidence/` 中。

## 准备与记录

使用允许修改的测试项目和独立测试会话。记录提交版本、Node 与 Codex 版本、操作系统、客户端版本、访问方式及结果；公开记录使用示例域名、路径和机器名称，隐藏会话内容及认证信息。

结果区分 `passed`、`failed`、`blocked` 和未执行；只将实际完成的检查标记为通过。浏览器移动视口、模拟器、实体手机，以及局域网、公网 HTTPS 和蜂窝 WSS 分别记录。

## 自动化与只读诊断

```sh
npm run check
npm run doctor
```

`check` 执行格式、隔离自动测试与网页构建。`doctor` 使用本机配置连接已有共享后端，进行握手和只读查询，不创建任务。远端诊断使用 `npm run doctor -- --target <目标ID>`；网络和后端错误应分别记录。

## 真实后端自动检查

```sh
npm run test:live -- --run
```

不带 `--run` 时仅显示说明。脚本连接配置中的本机共享 socket，创建隔离工作目录和测试会话，检查文字、第二连接实时事件、运行中追加与停止；会请求执行一次 `/bin/sleep 20`。它不启动新后端，不接续已有工作会话，也不自动批准请求。

报告保存到 `tmp/live-acceptance/report-*.json`。`passed` 只表示报告列出的自动检查成功，`fullAcceptance: manual_pending` 表示仍需完成下方人工检查。权限导致的 `EPERM` 或 `EACCES` 应记录为阻塞，不能当作通过。该脚本不代替 SSH 目标、Desktop/CLI 与真机验证。

## 共享会话与控制

- [ ] Desktop 和 CLI 的测试会话可在客户端找到，正文、工作路径和历史分页正确。
- [ ] 客户端创建新会话，项目、模型、推理强度与 Plan 模式生效，电脑端可接续。
- [ ] 电脑启动持续输出的任务，手机能看到增量回复和工具过程。
- [ ] 手机追加指令后仍为同一轮次，没有另起重复任务。
- [ ] 手机停止任务后电脑端同步停止，没有影响其他会话。
- [ ] 文字和图片成功到达模型，历史图片可回显；上传失败不会意外启动任务。
- [ ] 命令与文件变更审批可处理；另一个客户端处理后，旧审批失效。
- [ ] 交互问题显示并提交正确，敏感输入不出现在普通日志中。
- [ ] 对不能共享运行状态的来源，明确记录限制，不以历史可读判定实时控制成功。

必须确认各端连接同一个已有后端。独立 `codex exec resume` 等运行路径应单独验证，不能用共享 socket 的交互式 CLI 结果代替。

## 目标机器与隔离

- [ ] 本机和 SSH 目标分别完成文字、图片、追加、停止与审批操作。
- [ ] 切换目标后，模型、目录、会话与当前机器一致。
- [ ] 相同会话 ID 或目录名称不会使草稿、附件、图片和审批跨目标复用。
- [ ] 单台机器离线不影响其他目标；恢复连接后状态正确。
- [ ] 未配置远端图片目录或 SFTP 不可用时，文字功能仍可使用，图片显示具体限制。
- [ ] 网关重启后，远端历史图片映射与设备授权恢复。

## 连接恢复与认证

- [ ] 锁屏、刷新及切换网络后，恢复会话和运行状态；待处理审批恢复或显示需要在电脑处理的限制。
- [ ] 发送后立即断网，恢复时不会自动重复提交，能核对最新历史。
- [ ] 网关重启后客户端同步快照，Codex 原任务继续，事件不串到其他会话。
- [ ] 两个客户端处理同一审批，仅第一次有效。
- [ ] 配对凭据使用后或超过 5 分钟不能再次兑换。
- [ ] 未配对客户端不能读取会话、设备或上传图片；不允许的来源不能操作网关。
- [ ] 同一客户端重复配对复用记录；不同浏览器或不同安装身份保持隔离。
- [ ] 撤销或退出后，对应客户端全部入口的 HTTP 请求被拒绝，现有 WebSocket 关闭。

## 手机与网络

- [ ] iPhone Safari、Android Chrome 分别验证输入法、长对话滚动、代码块、图片和草稿恢复。
- [ ] 局域网从实体手机完成配对、生成、追加、停止和恢复。
- [ ] 公网 HTTPS 健康检查与 TLS 验证通过；HTTPS 页面使用 WSS，无混合内容。
- [ ] 手机关闭 Wi-Fi，使用蜂窝网络完整执行配对与会话控制，不以健康接口成功替代 WSS 验证。
- [ ] 使用后台服务时，分别验证服务重新加载、进程异常恢复与电脑重新登录后的访问。

HarmonyOS 的构建、凭据与界面检查另见[原生验收清单](HARMONYOS-ACCEPTANCE.md)。记录中保留未覆盖项目和具体错误，完成全部适用检查后再声明该环境验收通过。
